# Dripperz

A planned responsive rebuild of the Dripperz Phase 3 showcase, preserving its cyberpunk identity without wallet, minting or blockchain-data integrations.

## Status

This repository currently contains only the initial documentation bootstrap. The application, automated checks and deployment configuration have not been implemented.

The planned source foundation uses React, Vite and strict TypeScript. Product features and delivery infrastructure will follow in separately reviewed milestones.

This repository does not replace or modify the existing live site at <https://dripperzcyberclub.netlify.app/>.
